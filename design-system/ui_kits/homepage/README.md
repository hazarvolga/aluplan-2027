# Tasarım sistemi ana sayfa kesiti

22.10.2026 — Geçici kabul edilen ana sayfa yerleşiminin gerçek Aluplan Design System bileşenleriyle hazırlanmış bağımsız görsel kesitidir. Next.js entegrasyonu, nihai tasarım, canlı içerik/schema değişikliği veya yayın değildir.

Gösterilen alanlar: düz menü temsili, hero, beş hızlı bağlantı, üç rol ve her rolde görünür kalan altı ürün, beş çözüm bağlantısı, altı paket için PDF erişimi, 20 hizmet/kaynak kaydı, BIMFlex ortaklık alanı, üç ALLPLAN 2026 yeniliği ve footer. Header paketinin düz menü sınırı nedeniyle mega menü, arama ve tema kontrolü uygulanmadı. Kullanıcı kararıyla header CTA içermez; `Teklif İste` ve `Ücretsiz Deneme` yalnız hero'dadır. Hero videosu temsilî alandır. Form veya JSON-LD yoktur; teklif/deneme yalnız mevcut dış hedef bağlantılarıdır.

BIMFlex alanı FlexSoft tarafından geliştirilen ayrı çözüm ve Aluplan satış ortaklığı olarak sunulur; ALLPLAN paketi gibi sınıflandırılmaz. `saatlerden saniyelere` kaynak iddiası güçlendirilmeden korunur ve yayın öncesi kanıt bekler. `ALLPLAN 2026` kaynak sürüm etiketidir; güncel sürüm statüsü atanmaz. Paket kartları ve bölüm eylemi aynı mevcut PDF hedefini korur; fiyat eklenmez.

Tasarım sistemi `../../styles.css` ve `../../_ds_bundle.js` üzerinden, kabul edilen antrasit önizleme tokenlarıyla çalışır. İçerik `../../../homepage-wireframe/data.js` kaynak eşlemesini kullanır. UI kit React/Babel CDN prototipidir; üretim Next.js uygulamasına kopyala-çalıştır sayılmaz.

Açılış: proje kökünden HTTP sunucusu çalışırken `/docs/previews/anthracite-demo/ui_kits/homepage/`.
