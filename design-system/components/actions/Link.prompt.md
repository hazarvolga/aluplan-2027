Text link. `inline` inside prose, `standalone` for "more" links outside text.

```jsx
<Link href="/egitim">Eğitim takvimi</Link>
<Link href="/paketler" variant="standalone">Tüm paketler</Link>
```

Do not underline links, including on hover. Keep links distinguishable using context and visible focus treatment; check contrast and accessibility in prose. On brand surfaces the color switches to --text-on-brand.
